0. Contexte & Philosophie
Portefolia propose 46 templates de portfolio répartis sur 4 plans. Le problème actuel : les templates manquent d&apos;âme et de personnalité. Les utilisateurs du plan Essai disent que leur portfolio &apos;ne donne pas envie&apos;.
Le vrai problème identifié — Pourquoi les templates actuels &apos;n&apos;ont pas d&apos;âme&apos;
1. Hiérarchie typographique plate — tout a la même taille et le même poids
2. Hero section générique — juste nom + titre sur fond blanc pur
3. Zéro microinteraction — aucun effet au survol, aucune transition, aucune animation
4. Pas de personnalité visuelle — template &apos;clean-modern&apos; sans couleur distinctive
5. Sections sans identité — rien ne guide le regard du visiteur
6. Fond blanc pur (#FFFFFF) = froid et clinique — jamais pour un portfolio
La solution — 3 principes fondamentaux
PRINCIPE 1 : Chaque template a une PERSONNALITÉ, pas juste une couleur différente
  → Un nom évocateur, un registre émotionnel, un public cible précis
PRINCIPE 2 : La hiérarchie typographique est la colonne vertébrale de chaque template
  → Écarts de taille significatifs : 64px → 22px → 16px — jamais 2 éléments identiques
PRINCIPE 3 : Les microinteractions sont obligatoires sur TOUS les templates
  → Hover sur cards, transitions de sections, fade-in au scroll
Règles communes à tous les 46 templates
Élément
Règle universelle
Interdit
Fond principal
Jamais #FFFFFF pur — toujours une nuance légèrement teintée
#FFFFFF pur comme bg-white
Nom utilisateur
Minimum 48px / font-weight 700 — pas négociable
16-24px comme le body text
Titre métier
Couleur accent définie par le template, 18-22px
Même couleur que le nom
Labels de sections
UPPERCASE / 11px / letter-spacing 0.08em / couleur accent
Taille normale, pas d&apos;accent
Cards projets
Hover obligatoire : translateY(-4px) + shadow / transition 0.3s
Cards sans état hover
Hero section
Un visuel distinctif : dégradé, couleur, texture, ou image
Fond blanc uni sans accent
Bio utilisateur
16px / line-height 1.7 / couleur secondaire — jamais noire pure
14px compact sans respiration
Données manquantes
Affichage conditionnel — si pas de photo, fallback élégant
Espace vide ou placeholder moche

STRUCTURE (sections dans l&apos;ordre)
════════════════════════════════════════════
1. NAVIGATION
   Logo/Prénom à gauche (lien vers haut de page)
   3 liens à droite : À propos · Projets · Contact
   bg: #FAFAFA sticky, border-bottom: 1px solid #E8E8E8
2. HERO SECTION
   Layout : centré, padding-top 80px, padding-bottom 80px
   Fond : dégradé subtil from #FAFAFA to #F0F7F0 (très léger vert)
   Avatar/Photo : cercle 96px, border: 3px solid accent
     Fallback si pas de photo : initiales sur fond accent, texte blanc
   Nom : Inter 700 / 48px / #1A1A2E
   Titre métier : Inter 400 / 18px / couleur accent
   Bio courte (1-2 lignes max)
   2 boutons côte à côte :
     Primaire : "Voir mes projets" — bg accent, text blanc, radius 8px
     Secondaire : "Me contacter" — outline accent, radius 8px
   Icônes réseaux sociaux sous les boutons (LinkedIn, GitHub, email)
3. SECTION À PROPOS
   Label : "À PROPOS" en uppercase accent
   Sous-titre : "Qui suis-je ?"
   Layout 2 colonnes (texte gauche / compétences droite)
   Bio complète (texte brut)
   Compétences : pills colorées groupées par catégorie
     bg: #E8F5E9, text: #2E7D32, radius: 20px, padding: 4px 12px
4. SECTION PROJETS
   Label : "PROJETS"
   Grid 2 colonnes (1 colonne mobile)
   Card projet :
     bg: #FFFFFF
     border: 1px solid #E8E8E8
     border-radius: 12px
     padding: 16px
     Image projet en haut (ratio 16/9, object-fit: cover)
     Titre projet : Inter 600 / 15px
     Description courte : 2 lignes max, #5C5C5C
     Tag catégorie : pill accent
     HOVER OBLIGATOIRE :
       transform: translateY(-4px)
       box-shadow: 0 8px 24px rgba(0,0,0,0.10)
       transition: all 0.3s ease
       border-color: accent
5. SECTION COMPÉTENCES (si données)
   Label : "COMPÉTENCES"
   Pills groupées par catégorie
   Catégorie label : 11px uppercase #5C5C5C
   Pills : même style qu&apos;à propos
6. SECTION CONTACT
   Label : "CONTACT"
   Email cliquable : grand, accent
   Liens réseaux sociaux : icônes + label
   Localisation si disponible
7. FOOTER
   "Portfolio créé avec Portefolia · © 2026 [Nom]"
   bg: #1A1A2E, texte blanc, 14px
